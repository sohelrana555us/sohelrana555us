# দোকানের বাকি খাতা — সাবিহা কসমেটিক্স

বাংলা ভাষার একক-ব্যবহারকারীর দোকানের বাকি খাতা PWA।

## প্রকাশ
GitHub repository settings → Pages → Deploy from a branch → main → /(root) → Save.

## ব্যবহার
- গ্রাহক, ছবি, মোবাইল ও ঠিকানা যোগ করুন।
- বাকি ও জমার লেনদেন যোগ করুন।
- ব্যাকআপ বোতামে JSON ডাউনলোড করুন; দরকার হলে ব্যাকআপ ফেরত নিন।

## গুরুত্বপূর্ণ
তথ্য এই ডিভাইসের ব্রাউজারের localStorage-এ থাকে। ব্রাউজারের ডেটা মুছে গেলে হিসাব হারাতে পারেন, তাই নিয়মিত ব্যাকআপ রাখুন। এই সংস্করণে অনলাইন ক্লাউড সিঙ্ক নেই।
